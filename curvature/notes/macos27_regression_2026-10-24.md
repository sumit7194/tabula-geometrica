## verify.sh (the regression gate, on the Accelerate-linked .venv)
- **All scientific gates PASS (67 PASS lines).** The only failure was the cross-repo dependency census: two
  undeclared sibling-repo reads (193 → conjecture_machine's sealed TS2 metric; 197e → TheBridge's sealed V13 JSONs).
  Both are now declared with independence scoping (8b9bdea); the census and its self-test pass.
- First launch false-killed by the watchdog: a fresh boot has NO swap file (total = free = 0), which the swap rule
  read as "swap exhausted". Fixed: the rule applies only when a swap file exists (b22b436).
- **Memory:** whole-tree peak 14,971 MB. The heavy steps are 161 (7.7 GB), 162 (8.0 GB) and 167 (6.8 GB). They run one
  at a time, but on this 16 GB shared machine that is enough to pressure other users' jobs. Not new, but now measured.
